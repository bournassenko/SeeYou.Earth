# SeeYou.Earth

SeeYou.Earth is an open-source project to make astronomical observations easier to explore.

## Project status

- Implemented: a static homepage built with Astro, SolidJS, and TypeScript.
- Planned: a sky explorer with celestial coordinate input and real astronomical observations.

## Local development

Use Node.js 24 and npm.

```sh
npm ci
npm run dev
```

Open the local URL printed by Astro.

## Validation

```sh
npm run format:check
npm run check
npm run build
npm run preview
```

The production build is written to `dist/`.
